# Volante — dummy n.º 0

Maqueta web de la revista *Volante*: portada, hojeo de páginas en 3D e índice con mouse-over.

Sitio estático, sin build: `index.html` + `portada.jpg`.

## Publicar

- **Vercel:** importar el repo, framework "Other", sin comando de build, directorio de salida `./`.
- **Local:** abrir `index.html` en el navegador.

Los textos interiores son simulados (lorem ipsum).
